# FPL Scoring Rules — 2026/27 Season

Reference document for The Gameweek Lab. Use these values as ground truth when analyzing player performance, captaincy picks, and differentials.

## Points by Action

| Action | Points |
|---|---|
| Playing up to 60 minutes | 1 |
| Playing 60+ minutes (excl. stoppage time) | 2 |
| Goal scored — Goalkeeper | 10 |
| Goal scored — Defender | 6 |
| Goal scored — Midfielder | 5 |
| Goal scored — Forward | 4 |
| Assist (any position) | 3 |
| Clean sheet — Goalkeeper/Defender | 4 |
| Clean sheet — Midfielder | 1 |
| Clean sheet — Forward | 0 |
| Save (per 3 saves) — Goalkeeper | 1 |
| Penalty save | 5 |
| Penalty miss | -2 |
| Yellow card | -1 |
| Red card | -3 |
| Own goal | -2 |
| Goals conceded (per 2, GK/DEF only) | -1 |

## Defensive Contribution (DEFCON) — new mechanic, kept for 2026/27

Rewards defensive work outside of clean sheets:
- **Defenders:** 2 points for reaching 10+ combined Clearances, Blocks, Interceptions, Tackles (CBIT) in a match
- **Midfielders/Forwards:** 2 points for reaching 12+ combined Clearances, Blocks, Interceptions, Tackles, Recoveries (CBIRT) in a match
- Capped at 2 points per match regardless of how far the threshold is exceeded

## Bonus Points System (BPS)

- Awarded to the top 3 performers (by BPS score) in each match: 3 / 2 / 1 points
- BPS is calculated from ~32 in-match stats (goals, assists, clean sheets, key passes, tackles, saves, fouls, offsides, big chances missed, etc.)
- Ties split points evenly per official tie-break rules
- **New for 2026/27:** projected bonus points are shown live from the 20-minute mark of each match and update as the game progresses

## Squad & Transfer Rules

- **Budget:** £100.0m to build a 15-player squad
- **Club limit:** max 3 players from any single Premier League club
- **Starting XI formation:** 1 GK + at least 3 DEF + at least 2 MID + at least 1 FWD (11 total, 4 on bench)
- **Free transfers:** 1 per gameweek, rolls over up to a maximum of 5 banked
- **Extra transfers:** cost -4 points each beyond your free transfers

## Chips (2 sets across the season — 8 chips total)

- Wildcard, Free Hit, Triple Captain, Bench Boost — one of each per half of the season
- First set must be used before the Gameweek 19 deadline (13:30 GMT, Saturday 2 January 2027)
- Unused first-half chips do not carry over to the second half

## Other 2026/27 Notes

- Live updates: overall rank and mini-league positions now update in real time during matches, not just after
- Price Change Predictor and enhanced career stats are new tools available in-app
